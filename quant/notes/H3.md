# H3 — Prop-firm challenge as a barrier problem
Model: account P&L X_t = μt + σW_t (per day), target +a, loss limit −b. Scale function s(x)=e^{−2μx/σ²} ⇒ P(pass) = (1−e^{2μb/σ²})/(e^{−2μa/σ²}−e^{2μb/σ²}); μ=0 ⇒ b/(a+b) (gambler's ruin). Depends only on μ/σ² × barrier sizes.
Example a=6%, b=4% (static), 20k MC paths daily steps (MC slightly above formula: discrete overshoot):
- no edge: 40% (formula) / 41% MC static / 29% with trailing EOD drawdown (floor = min(peak−b, 0)).
- costs only −0.05%/day: 29% / 28% / 20%. Same costs at 3× size: 36% / 37% / 31% → with negative edge, BIGGER size raises pass odds ("bold play", Dubins & Savage) — explains why gamblers pass by swinging big.
- Sharpe 1, 1% daily vol: 55% / 58% / 43%. Sharpe 2, 1%: 69/72/56. Sharpe 2, 0.5%: 87/89/73 but median 68 days.
- 93% pass (static) requires annual Sharpe 5.24 at 1% daily vol (16 days), 2.62 at 0.5% (60 days), 1.31 at 0.25% (227 days).
- Trailing drawdown cuts pass rates ~11–16 points.
Implication for Thomas's 93% claim: plausible only with small daily vol relative to the loss limit AND a genuinely high Sharpe, accepting a long time to pass; a 93% figure from resampling a backtest inherits the backtest's Sharpe estimate (Modules 08/10). One pass = n of 1.
Break-even: fee F, pass prob P ⇒ need expected payout per pass > F/P ($150 fee: $375 at 40%, $161 at 93%).
