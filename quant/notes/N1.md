# N1 — Out-of-sample test of Polymarket YES underpricing (7d before scheduled end, 5–95¢, event-clustered)
Split by scheduled end date: train < 2025-07-01 (178 markets / 103 events), test ≥ 2025-07-01 (432 / 282).
Train: outcome − price +.018; return per $1 at price +0¢ +4.2% (t .71), +1¢ −0.4%, +3¢ −8.1% → NO significant bias before mid-2025.
Test: outcome − price +.065; return per $1 +49.5% at +0¢ (t 3.66), +40.3% at +1¢ (t 3.50), +26.5% at +3¢ (t 3.07). (Mean returns are dominated by a few cheap contracts that won — payoffs are 1/p.)
Recalibration fitted on train (a +.13, b 1.15) did NOT improve test Brier (.1905 raw vs .1914) and a selective rule built from it earned −0.4% (t .13).
Conclusion: the YES underpricing is a recent (post-mid-2025) phenomenon in this sample, not something a trader could have learned from earlier data → treat as regime/sample-composition dependent (sports share grew; top-volume selection overweights recent markets). Classic lesson: an effect in the full sample may be concentrated in one period; walk forward before believing.
