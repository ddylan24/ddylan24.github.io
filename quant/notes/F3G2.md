# F3 — Fractional differentiation (López de Prado AFML ch.5)
(1−B)^d = Σ_k w_k B^k, w_0=1, w_k = −w_{k−1}(d−k+1)/k. Fixed-width window: drop weights |w|<1e−4.
Log SPY 1999–2026: d=0 ADF .93 (corr 1.000); .1 −.26 (.999); .2 −1.68 (.994); .3 −3.51 ✓ (.982); .4 −6.61 (.958); .5 −11.4 (.909); .8 −39.7 (.468); 1.0 −62.9 (.025).
→ d≈0.3 is enough for stationarity while keeping 0.98 correlation with price level; ordinary returns (d=1) keep 0.025. Matches AFML's finding (~0.35 on E-mini futures, corr ~0.995).
