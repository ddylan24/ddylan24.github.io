# O1 — Proper scoring rules
Expected score maximized by reporting the true probability (proper): Brier −(r−y)², log ln r_y. Check: truth .7 → Brier argmax .70, log .70; linear score (r for YES, 1−r for NO) argmax .99 (improper — rewards exaggeration).
LMSR is the market version of the log scoring rule: trader who moves price p0→p1 earns b·[ln p1(outcome) − ln p0(outcome)]: 0.5→0.6 YES pays 18.232 = 100·ln(.6/.5) ✓; 0.5→0.9 pays 58.779 ✓ (Hanson 2003).
Polymarket 7d-before prices: log loss .3801 vs base-rate .6139 → skill 38% (Brier skill 45%); log loss dominated by confident misses (price .006 that won; .971 that lost; .030 that won).
# O2 — Monte Carlo variance reduction (BS call S=K=100, T=1, r=4%, σ=20%; true 9.9251; N=20,000; 300 reps)
plain sd .1007; antithetic (Z,−Z) sd .0675 (variance ×0.45); control variate with discounted S_T (known mean S0), β = Cov/Var: sd .0385 (variance ÷6.8).
Importance sampling for tails: P(30-day drop >20%, σ 20%): true 4.42e−5; plain MC 100k → 3.0e−5 (3 hits); mean-shifted IS (shift = threshold z, weight e^{−θZ+θ²/2}) → 4.41e−5 (0.2% error).
# O3 — Bayesian strategy evaluation & when to quit
Beta-binomial (flat prior): 55/100 wins → P(p>.5)=84.0%, 95% [.452,.644]; 110/200 → 92.1%; 550/1000 → 99.9% [.519,.581].
Skeptical prior Beta(1250,1250) (sd ≈1pt around 50%, encodes "most strategies have no edge"): 55/100 → mean .502, P(>.5) 57.8%; 550/1000 → .514, 95.5%. Priors matter enormously at small n.
SPRT (Wald) "edge gone (50%)" vs "intact (55%)", α=β=5%: LLR boundaries ln(.95/.05)=±2.94. If edge gone → detected after median 434 trades (96% correct); if intact → false alarm 4.2% (median 435 trades). Distinguishing a 5-pt edge from none takes hundreds of trades — decide the stopping rule in advance.
