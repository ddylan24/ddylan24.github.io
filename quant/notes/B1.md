# B1 — Itô's lemma and volatility drag
Derivation: dS = μS dt + σS dW. Taylor to 2nd order: df = f' dS + ½ f'' (dS)². Rules: (dW)² = dt, dW·dt = 0, (dt)² = 0 ⇒ (dS)² = σ²S² dt.
For f = ln S: f' = 1/S, f'' = −1/S² ⇒ d ln S = (μ − ½σ²) dt + σ dW.  Hence S_T = S_0 exp((μ−½σ²)T + σW_T).
E[S_T] = S_0 e^{μT} (mean grows at μ); median = S_0 e^{(μ−½σ²)T} (typical path grows at μ−½σ²). Volatility drag = ½σ².
Leverage L (daily rebalanced): growth g(L) = Lμ − ½L²σ² (+ financing: −(L−1)r_f) → max at L* = (μ−r)/σ² = Kelly. Kelly is Itô.
Verification:
- Quadratic variation: Σ(ΔW)² → 1 (=T): 0.968 (n=1e3), 0.9994 (n=1e5). Σ|ΔW| → ∞ (252 at n=1e5). Σ ΔW·Δt → 0.
- GBM μ=8%, σ=40%, 10y (200k paths): mean 2.23 = e^{0.8}; median 1.00 = e^{(0.08−0.08)·10}; P(lose money) = 0.50. Positive expected return, coin-flip typical outcome.
Real data (verified: Yahoo prices; T-bill from Ken French RF): 2009-07 → 2026-08, SPY CAGR ≈15.2%, μ 15.6%, σ 17.0%, drag 1.45%/yr.
- SSO (2x): actual 25.2% vs 2×SPY 30.3%. Model L·SPY − (L−1)·Tbill − fee(0.89%): 25.9%. Drag ≈ 1.6%, financing+fees ≈ 2.9%.
- UPRO (3x): actual 33.0% vs 3×SPY 45.5%. Model 34.6%. Drag ≈ 5.8%, financing+fees ≈ 5.1%.
- Remaining 0.7–1.6%/yr gap = swap spreads above T-bills, trading costs.
- Round trip −10%/+11.11%: index flat; 3x loses 6.67%.
Note: 2009–2026 was an unusually strong, low-drawdown bull market for 3x; hindsight Kelly μ/σ² = 5.4x is meaningless as a forecast (μ estimate error, Module 08).
