# B3 — Markov chains & HMMs on real data
Math: hidden state s_t ∈ {1..K} follows Markov chain A_ij = P(s_t=j|s_{t−1}=i); observation r_t | s_t=j ~ N(μ_j, σ_j²).
- Forward (filter, real-time): α_t(j) ∝ p(r_t|j)·Σ_i α_{t−1}(i)A_ij, normalized each step → P(s_t | r_1..r_t).
- Backward β and smoothing: P(s_t | r_1..r_T) ∝ α_t·β_t — uses FUTURE data. Viterbi (most likely path) also uses the whole sample.
- Baum–Welch = EM: E-step forward–backward, M-step re-estimate A, μ, σ. Local optima → multiple random starts (used 8, kept best log-lik).
- Stationary dist π solves πA = π; expected duration of state i = 1/(1−A_ii).
Data: CRSP value-weighted market (Ken French Mkt-RF+RF) daily — verified source; fit 1926–1999 (n=19,612), test 2000–2026 frozen params.
Fit: CALM μ +20.5%/yr σ 9.6%, stay .9862 → 73 days; TURBULENT μ −34.3%/yr σ 31.0%, stay .9436 → 18 days. Stationary 80/20.
OOS 2000–2026 (signal next day, cash = T-bill):
- Buy & hold: CAGR 8.6%, Sharpe 0.42, maxDD 54.6%.
- Filtered P(calm)>0.5: CAGR 5.3%, Sharpe 0.36, maxDD 37.5%, 584 switches (costs not included!).
- SMOOTHED (look-ahead): CAGR 15.2%, Sharpe 1.43, maxDD 8.8% — fake. Same model, same data; only difference = using future info.
- Vol-scaled to 15% using filtered state vol: CAGR 7.5%, Sharpe 0.47, maxDD 36.8%.
- Filter flagged turbulence 2008-09-02 and 2020-02-24 (quick), but switches too often; regime "mean" is mostly in-sample labeling of realized returns, the useful out-of-sample content is VOLATILITY, not direction.
Lesson: HMMs are good volatility-regime detectors, poor direction predictors; smoothed/Viterbi labels in a backtest = look-ahead bias that turns Sharpe 0.36 into 1.43.
