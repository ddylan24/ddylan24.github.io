# A4 — Bootstrap: iid vs stationary block bootstrap
Math: iid bootstrap resamples single observations with replacement → destroys all serial dependence.
Stationary bootstrap (Politis & Romano 1994): blocks start at random points, block lengths ~ Geometric(p=1/L), wrap around; resampled series is stationary. Optimal L: Politis–White (2004) (arch.optimal_block_length). On |SPY returns| it gives L≈172 days (vol persistence is long).
Results:
- SPY buy&hold 2000–2026 (SR .51, actual maxDD 55.2%): iid median DD 47.1% (95th 68.5%); stationary L=40 44.8% (65.7%); L=172 50.7% (70.3%). → Similar. Daily SPY returns are ~uncorrelated (lag1 −0.08) even though |returns| are very persistent (ρ 0.28/0.33/0.22 at 1/5/20 days). Volatility clustering alone doesn't make iid drawdowns badly wrong here.
- SPY 200d trend filter (SR .62, maxDD 27.3%): iid median 28.4%, stationary 27.6%. Similar.
- Known-truth test: strategy whose MEAN depends on a persistent regime (good regime +0.12%/day, bad −0.25%/day, switch probs .01/.03), 10y daily. TRUE maxDD median 41.3% (95th 66.0%). iid bootstrap of one path: 21.5% (34.2%) — understates by half. Stationary L=60: 35.8% (58.5%) — much closer. Path lag-1 autocorr only 0.064: tiny autocorrelation, huge drawdown effect.
Lesson: block bootstrap matters when the EDGE itself clusters (regime-dependent strategies, trade sequences where losses cluster). For plain index returns iid is roughly fine. Always prefer block bootstrap; costs nothing.
