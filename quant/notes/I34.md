# I3 — Adverse selection
Glosten–Milgrom (1985): value V∈{VL,VH}, prior p; share π informed. ask = E[V|buy], bid = E[V|sell]; initial spread = π(VH−VL). Sim (π=.3, VH−VL=2, true=high, 2000 runs): spread .600 → .290 after 10 trades → .086 after 30; mid 100.00 → 100.53 → 100.86. Spread ∝ informed share; prices learn from order flow; spread compensates the dealer for losing to informed traders.
Kyle (1985): v~N(0,σv²), noise u~N(0,σu²). Equilibrium: x=β(v−p0), β=σu/σv; p=λy, λ=σv/(2σu); half the private info revealed (Var(v|p)=σv²/2); insider profit σuσv/2. Sim (σv=2, σu=1, 400k): λ 1.00 ✓, Var ratio .500 ✓, profit 1.002 vs 1.000 ✓. Trading more aggressively (β=1) → profit ≈ 0; less (β=.25) → .751. Kyle's λ = market depth: price impact per unit order flow.
Roll (1984) spread estimator s=2√(−Cov(Δp_t,Δp_{t−1})) on 2y daily: SPY → 54 bp, IWM 63 bp, UPST 260 bp. SPY's true quoted spread ≈ 0.1–0.3 bp → estimator fails: daily negative autocov is short-term reversal, not bid-ask bounce. Model assumptions (only bounce causes negative autocorr) must hold.
# I4 — Range-based volatility
Parkinson σ²=(ln H/L)²/(4ln2); Garman–Klass ½(ln H/L)² − (2ln2−1)(ln C/O)²; Rogers–Satchell ln(H/C)ln(H/O)+ln(L/C)ln(L/O) (drift-robust); Yang–Zhang = overnight + k·open-close + (1−k)·RS.
Sim (intraday GBM, 390 steps, no gaps): efficiency vs close-close: Parkinson 5.2× (theory 5.2), GK 8.3× (theory ~7.4), RS 6.5×; discretely-sampled highs/lows bias range estimators down 6–9%.
Real SPY 1999–2026: close-close vol 19.2%, Parkinson 15.8%, GK 16.0% — overnight gaps = 34% of variance; range estimators miss it unless added back.
Forecast next-month close-close variance from last month (QLIKE): close-close .4728; Parkinson+overnight .3939; GK+overnight .3905 → ~17% better forecasts from the same daily bars.
