# W4: How big are the liquidity subsidies? Polymarket vs Kalshi census (2026-10-15)

**Data.** Polymarket CLOB `GET /rewards/markets/current` (cursor paging; fields total_daily_rate, rewards_max_spread, rewards_min_size). Kalshi `GET /trade-api/v2/incentive_programs?status=active` (notes/LIP.md). Script: `code/w4_pm_rewards.py`.

| | Polymarket | Kalshi LIP |
|---|---|---|
| markets with live rewards | **18,649** | 5,734 programs (4,764 lasting ≥1 day) |
| total per day | **≈ $210k** | **≈ $129k** from ≥1-day programs (+ short hourly programs) |
| median per market-day | **$3** | $14 |
| 90th percentile / max | $22 / $2,000 | max $2,400/day as a rate (short programs) |
| distance rule | max spread 4.5¢ (12.3k markets), 6.5¢, 5.5¢, 8.5¢, 2.5¢ | DF^ticks, DF 0.4–0.5 |
| size rule | min size 20 (14.6k markets), 50, 30, 100 | Target 300–2,500 per side |

- **Correction to LIP.md:** the headline "$324k/day" summed *rates* across programs, including 1-hour programs (e.g., $100/hour reads as $2,400/day). Programs lasting at least a day total **$129k/day**. Short programs add their actual pools on top, but only during their windows.
- **Together, about $340k/day ($120M+/yr) is spent subsidizing prediction-market liquidity.** It's thinly spread: most markets carry a few dollars a day, and a small number of flagship markets carry $1–2k/day.
- At $3/day, a market only pays for quoting if adverse selection there is tiny. The money is in the top few hundred pools on each venue, which is where competition (W3) concentrates.
