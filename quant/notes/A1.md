# A1 — Hypothesis tests on event outcomes (SPY daily sweep replication)

## Math
- Mean outcome x̄, std s, n events. SE = s/√n. 95% CI = x̄ ± 1.96·SE (CLT; needs finite variance, ~independent obs).
- t = x̄/SE. |t|>1.96 ⇔ CI excludes 0 (two-sided 5%). With many tests use t>3 (HLZ).
- Test the RIGHT null: event outcome vs unconditional outcome (baseline), not vs 0. Welch-type excess: e_i = x_i − mean(all days).
- Overlapping outcome windows (10-day barrier from consecutive days) are autocorrelated: ρ1=0.62, ρ2=0.44, ρ5=0.19 on SPY.
  Effective sample size n_eff ≈ n / (1 + 2 Σ_k (1−k/n) ρ_k). Naive SE understates true SE by √(n/n_eff).
  Fixes: block bootstrap (resample blocks of consecutive obs), Newey-West HAC SE, or non-overlapping sampling.

## Real-data result (SPY daily 1999-01 → 2026-10, auto-adjusted; ATR14; barriers ±1.5 ATR; 10-day limit)
Event defs on DAILY bars: bearish sweep = high > prior high & close < prior high; bullish = low < prior low & close > prior low.
- Full sample: baseline mean +0.150% (t=5.44, inflated by overlap); bullish +0.145% (t=2.18, "significant" vs 0) but excess vs baseline −0.006% (t=−0.09). Bearish +0.059% (t=0.91), excess −0.092% (t=−1.44).
- 2023 only: bear +0.101%, CI [−0.44,+0.65]; n=38. 2022–2025: bear +0.222% n=168.
- No sub-period (1999–08, 2009–16, 2017–26) shows a significant excess vs baseline for either sweep (|t| ≤ 1.44).
- P(upper barrier first) after sweeps ≈ baseline in every period.
- Block bootstrap CI (blocks of 10 events) for full-sample bear mean: [−0.111, +0.224] vs naive [−0.067, +0.184] — ~30% wider.

## Lessons
1. The bullish "edge" is SPY's upward drift. Compare against the baseline (Thomas QP03 point) — confirmed on real data.
2. Daily SPY shows no sweep effect. Thomas tested ES intraday (his bars were finer), so this is not a direct replication; it says the effect, if any, doesn't survive at daily scale.
3. Overlapping windows inflate t-stats — even the baseline's t=5.4 is overstated.
