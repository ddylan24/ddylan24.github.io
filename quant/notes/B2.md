# B2 — Ornstein–Uhlenbeck
dX = θ(μ−X)dt + σdW. Exact solution over Δ: X_{t+Δ} = μ + (X_t−μ)e^{−θΔ} + σ√((1−e^{−2θΔ})/(2θ))·ε.
⇒ exactly an AR(1): X_{t+1} = a + bX_t + e with b = e^{−θΔ}, μ = a/(1−b), θ = −ln(b)/Δ, σ = sd(e)·√(2θ/(1−b²)). OLS on (X_t, X_{t+1}) = conditional MLE.
Half-life = ln2/θ. Stationary distribution N(μ, σ²/(2θ)).
Small-sample bias (Kendall/Marriott–Pope): b̂ biased down ≈ −(1+3b)/T ⇒ θ̂ too high ⇒ half-life too SHORT. Simulation, true HL 43.7d: 1y data median est 22.3d (10–90%: 10.6–59); 3y 33.8d; 10y 41.0d; 30y 42.0d. → short samples make mean reversion look faster (and more tradable) than it is.
Real (FRED, verified): VIX 1990–2026 half-life 30 trading days (log-VIX 34d, long-run level 18.2); by period 42d (1990–07), 35d (2008–19), 20d (2020–26) — speed itself drifts. 10y–2y spread 1976–2026: half-life ≈548 trading days (~2.2 yrs), mean 0.83%. HY OAS (FRED only 2023-10→, licensing) half-life 31d — only 3y of data so likely biased short. ADF: VIX stat −7.34 (p≈0), T10Y2Y −3.57 (p=0.0065).
Caveat: a mean-reverting index ≠ tradable. VIX is not investable; VIX futures embed the expected reversion (contango, roll yield) — see D3.
