# A3 — Multiple testing (real SPY experiment)
Math:
- M independent tests at α: P(≥1 false positive) = 1−(1−α)^M (42 tests → 88%).
- Bonferroni: reject if p < α/M (controls family-wise error rate, FWER). Holm: sort p ascending, reject p_(i) < α/(M−i+1) until first failure (uniformly more powerful, still FWER).
- Benjamini–Hochberg: sort p; find largest i with p_(i) ≤ i·q/M; reject 1..i. Controls false discovery rate (expected share of false discoveries) — the right tool for exploratory feature search.
- HLZ: t>3 ≈ p<0.0027 ≈ Bonferroni-style hurdle for the factor zoo.
- Dependence matters: correlated features + overlapping outcomes make the null count of "hits" larger and more variable than α·M. Use a placebo/permutation test: rerun the whole search on random event dates.
Experiment: 1,555 bearish-sweep days on SPY 1999–2026, 42 plausible context splits (SMA position, momentum, vol regime, ATR ratio, volume, wick, day-of-week, quarter, gaps, inside bar, near high, month start/end), outcome = 5-day forward return, Welch t-test split vs rest.
- Naive p<0.05: 6. Placebo (300 runs of random dates): mean 6.1 hits, 95th pct 13, max 23 (vs 2.1 if independent). → 6 hits is exactly what noise produces.
- Survivor after Bonferroni/Holm/BH: above_sma5 (t=−3.59). But it's not sweep-specific: on ALL days, above-SMA5 → 5-day return −0.33% lower (t=−5.32; non-overlapping t=−3.07). It's generic short-term reversal, and it's decaying: 1999–08 t=−4.17, 2009–16 −3.68, 2017–26 −1.92. FIM: short-term reversal doesn't survive costs at scale.
Lesson: the one "real" finding wasn't about the event at all; check whether a context effect exists unconditionally before crediting the event.
