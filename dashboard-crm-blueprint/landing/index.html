How it works

Two lines of setup per client site

Control Center doesn't care what your client sites are built with. WordPress, Shopify, Flask, Next.js — if it can serve a script tag, it can feed the dashboard.

1

Add the client

Create the company record, pick the services they're on, and set the monthly fee. Recurring revenue and invoicing start from that moment.

2

Drop in the beacon

One script tag on their site starts the traffic feed. Uptime monitoring begins as soon as you save the URL — nothing else to install.

Questions

The things people ask first

Do my client sites have to be rebuilt to use this?

No. Uptime monitoring needs nothing but the URL, and traffic needs one script tag. Deeper metrics — bookings, orders, appointments — come from a small read-only collector we point at your client's existing data. Nothing about their site has to change.

Where does the data live?

Wherever you want it. Control Center runs happily on a single small server you control, or we host it for you. White-label instances are fully isolated — separate database, separate domain, separate backups.

Can clients see each other's numbers?

No. Every record is tied to the client it belongs to, and a client login is locked to a single company at the data layer — not just hidden in the interface.

Do you handle payments?

Both ways. Out of the box it keeps the ledger — invoices generate automatically and you mark them paid, which means no card data ever touches the system. If you'd rather collect automatically, it connects to Stripe and reconciles from there.

What if I only run one business, not an agency?

That works too. Single-business mode drops the multi-client layer and gives you the dashboard for your own site — bookings, revenue, customers and uptime in one place.
